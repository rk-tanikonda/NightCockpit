# Security

The application renders local videos or an HTTPS media URL configured by the user. It does not need root, Accessibility, Screen Recording or Full Disk Access. The optional launch agent runs in the logged-in user's GUI session.

Only configure sources you trust. Stream playback contacts the media host; the application does not load its surrounding website or embed analytics itself. No license tokens or browser cookies are copied from other applications.

Do not post credentials, private media links, or personal logs in public issues. If the repository offers private vulnerability reporting, use that channel. Otherwise ask the maintainer for a private contact method before sharing sensitive reproduction details.

There is no security-update service or support SLA. Build and inspect source changes before installing updates.
