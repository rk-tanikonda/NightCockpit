# Local media

This directory contains no distributed video or audio. Choose a local file through the app or pass it to `setup.command --video`.

To bundle a default with your own build, place a file you have permission to use at `Videos/wallpaper.mp4`. Build output includes that file; Git ignores it. The source-code licenses grant no rights to third-party footage.

When distributing a build containing media, keep its required attribution/license with the build and confirm you have redistribution rights.
